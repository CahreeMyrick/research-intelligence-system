## Ingestion Service

**Objective**: This service handles document loading, processing, and storage. 

### Overview
This service accepts a single document, or a collection of documents (folder), and constructs a structured corpus. It handles only document **loading**
and **parsing**. It does not create chunks or embeddings.

When documents are uploaded, they undergo the following stages:

<div style="margin-left: 40px">

##### 1. Wrap documents as type ```Document```
##### 2. Add documents to the ```Corpus```
##### 3. Save the finished corpus

</div>

### Schemas

```python
class Document(BaseModel):
    identity: DocumentIdentity
    metadata: DocumentMetadata
    sections: list[Section] = Field(default_factory=list)
    references: list[Reference] = Field(default_factory=list)
    page_count: int = 0
    warnings: list[str] = Field(default_factory=list)
```

```python
class Corpus(BaseModel):
    documents: list[Document] = Field(default_factory=list)
    
    def save(self, corpus_dir: str | Path) -> CorpusManifest:
        """Saves the structured document corpus.

        Args:
            curpus_dir: The corpus directory.

        Returns:
            The generated CorpusManifest.
        """
```

### Corpus Layout
```
corpus
├── chunks # not generated by ingestion service
│   ├── doc_1.json
│   ├── doc_2.json
│   └── doc_3.json
├── manifest.json
├── parsed
│   ├── doc_1.json
│   ├── doc_2.json
│   └── doc_3.json
└── raw
    └── pdf
        ├── doc_1.pdf
        ├── doc_2.pdf
        └── doc_3.pdf
```
